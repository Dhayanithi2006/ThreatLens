Quick Setup & Deployment Guide for Windows Administrators

Step 1: Enrol Endpoint

Click + Enrol New Computer above. Specify the target Windows hostname to generate a unique Collector ID and one-time secret token.

Step 2: Deploy Agent

Copy collector/ to the endpoint or run scripts\install.bat as Administrator. Saves config to C:\ThreatLensCollector\config.json.

Step 3: Enable Audit Policy

Administrator must manually enable: auditpol /set /subcategory:"Logon" /success:enable /failure:enable and Process Creation auditing.

Step 4: Verify Transmission

Execute python threatlens_collector.py --run-once. Watch table below transition from Enrolled to Actively Sending.
